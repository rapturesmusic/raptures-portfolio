# Raptures Portfolio

This is a self-contained static portfolio site. It has no build step, database, or framework.

## Run locally

Open `index.html` in a browser, or serve the `portfolio` folder with any static web server.

## Publish

Upload the contents of this folder to GitHub Pages, Netlify, Vercel, or any standard web host. Keep `index.html`, `styles.css`, and `script.js` in the same folder.

## Notes

- The release cards use public YouTube thumbnail URLs and link to the supplied music videos.
- Metrics are rounded and presented as public profile proof points. Refresh them before a major application if the source values change.
- Update the contact links in `index.html` if you want to add an email address, LinkedIn profile, or booking form.
